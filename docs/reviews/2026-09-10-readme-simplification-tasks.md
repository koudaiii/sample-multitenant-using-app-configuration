## 共有ルール（全タスク共通）

1. **1 タスク = 1 ファイル。** 別ブランチ／別エージェントで並行し、最後に任意順でマージする。
2. **見出しテキストを変更しない。** 他ファイルと相互リンクしているため、特に次は不可侵：
   - `samples/01-.../README.md` の `## 実ストアにデータを入れる`
   - `samples/01-.../README.md` の `## リクエストクォータと geo-replication`
   - 各サンプルの `## いつ選ぶか`
3. **正典は 01。** 実ストアへのデータ投入手順（11 件の `az appconfig kv set`、一時 Data Owner の
   付与と削除）は `samples/01` にだけフル記載する。02 / 03 / 04 は
  01 の `## 実ストアにデータを入れる` への相対リンク +
   **そのサンプル固有の差分だけ**にする。
4. **相互リンクは相対パス + GitHub 形式の日本語アンカー**（スペース→`-`、`:`・`(` などの記号は除去、
   英字は小文字）。例：`(#リクエストクォータと-geo-replication)`。
5. **削るのは重複・冗長表現のみ。** レビューの訂正内容・テスト名・リンク先の一次資料は残す。
6. 完了時に目標行数 ±20% 以内、リンク切れなし、
   [2026-09-06 レビュー](2026-09-06-independent-review.md)の指摘と矛盾しないこと。
